# Hotspot Premium

Lightweight, mobile-first captive portal prototype for MikroTik Hotspot.

## Status
Prototype UI v0.1. Login and package selection are currently demo interactions. MikroTik authentication, backend, payment gateway, and automatic hotspot provisioning are not connected yet.

## Structure
- `login.html` — captive portal UI
- `css/style.css` — lightweight responsive styling
- `js/app.js` — prototype interactions

## Roadmap
1. MikroTik Hotspot login/CHAP compatibility
2. Status, logout, and error pages
3. Backend API
4. Payment gateway + webhook verification
5. Automatic hotspot user/profile provisioning
6. Lightweight Android WebView wrapper
